# Veranda 🎨

Veranda is an ecommerce art gallery website that lets artists display their
artwork and sell it online. I built it to help sell my brother's artwork and
designed it as a clean, easy-to-browse storefront for any artist.

🔗 **Live site:** [https://superb-kringle-c2a3df.netlify.app]

## Features
- Gallery of artworks with images, titles, and prices
- Responsive design that works on phones and laptops

## Built with
HTML, CSS, JavaScript, deployed on Netlify


## What I learned
- Building a multi-section site (gallery, about, contact) with clean,
  semantic HTML and organized CSS
- Creating an image lightbox and scroll-reveal animations with JavaScript
- Designing a layout that keeps the focus on the artwork
- Deploying a site on Netlify and fixing file path problems, such as
  case-sensitive image names that work locally but break online
- Structuring a project for a real use case: selling an artist's work online]
